# clawd-pet

Clawd lives on top of the Claude Code prompt box and acts out what Claude is doing, with a `ctx: x% session: x%` meter in the top right, plus `credits: x%` when a spend limit reports and `cloud: $x.xx` in a cloud session.

```
/plugin install clawd-pet --marketplace cigarette1991/clawd-pet
```

Answer `y` to add the marketplace, then Enter for the user scope.
