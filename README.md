# nekoclaude

Clawd lives on top of the Claude Code prompt box and acts out what Claude is doing, with a `ctx: x% session: x%` meter in the top right, plus `week: x%` when a weekly limit reports, `credits: x%` when a spend limit reports and `cloud: $x.xx` in a cloud session.

```
/plugin install nekoclaude --marketplace anotherhabitanothertime/nekoclaude
```

Answer `y` to add the marketplace, then Enter for the user scope.
